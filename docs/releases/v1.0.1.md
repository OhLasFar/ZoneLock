A small update right after launch.

### Changes

- **New logo**: a "locked zone" (two zones, the big one carrying a keyhole), on the app icon, the tray icon and the settings window.
- **Plans**: an app launched by a plan now starts in its own folder, like a Start menu shortcut would. Some apps (Steam, for example) wrote files into ZoneLock's folder before.

Everything from [v1.0.0](https://github.com/OhLasFar/ZoneLock/releases/tag/v1.0.0) is included: maximize and F11 fullscreen kept inside zones, a layout per display, Shift + drag snap, plans 1-9, apps reopening where you left them.
