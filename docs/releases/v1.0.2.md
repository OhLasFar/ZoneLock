A bug fix for snapped windows.

### Fixed

- **Resizing a snapped window now resizes it.** Grabbing a border or a corner of a window that sits in a zone used to give the window back its pre-snap size and switch to moving it. ZoneLock now asks the window what is under the cursor: a border or corner is a resize (the window keeps the size you give it), the title bar is a move (the window gets its pre-snap size back, as before).
